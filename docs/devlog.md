### 2026-10-20 · Day 7: MCP Apps incident card
- Added `ui://nightwatch/incidents.html` through the SDK's `Apps` extension (`mcp==2.3.0`). The card is one self-contained file: inline CSS/JS, no URLs or network calls, and incident text only ever reaches the page as plain text (`textContent`).
